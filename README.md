# andersonmavi30.github.io

🇨🇴 [Español](README.es.md)

Personal technical portfolio and bilingual website of **Anderson Martinez Virviescas**, focused on networking, firewalls, Linux, virtualization, cloud, load balancers, Network Automation, NetDevOps, DevNet and AI-related infrastructure topics.

The site is published with **GitHub Pages** and served through the custom domain **andersonmvnetworks.com**.

## 🌐 Main Site Features

- Bilingual **Spanish / English** content
- Dark / Light theme
- Responsive portfolio layout
- Professional profile and experience
- Technical stack and infrastructure tooling
- Certifications with Credly verification links
- Projects and Network Automation labs
- Technical content and Medium articles
- Training / learning section
- Contact form powered by Formspree
- Links to GitHub, GitLab, Docker Hub, LinkedIn, YouTube and PNetLab
